\chapter{Introdução}

Elemento-chave para superar desafios e enfrentar a concorrência intensa.
A implementação de sistemas automatizados se configura como uma estratégia
essencial para otimizar operações e responder de forma ágil às dinâmicas
demandas do mercado.
Este trabalho de conclusão de curso dedica-se à apresentação e análise
detalhada de um projeto de automação desenvolvido para atender às
necessidades operacionais específicas da confeitaria Rô Bolos. O Sistema Web
Administrativo proposto desempenha um papel estratégico, contribuindo de
maneira significativa para a gestão eficiente de estoques, aprimoramento de
processos e o Website de Divulgação traz a promoção de um catálogo
consolidado.
No âmbito desta pesquisa, busca-se proporcionar uma visão abrangente,
delineando com precisão o projeto e estabelecendo limites temporais e
espaciais. A justificativa para a automação encontra respaldo na necessidade de
manutenção da competitividade no mercado, enquanto a definição de objetivos
específicos estabelece uma base sólida para o desenvolvimento e a
implementação do sistema automatizado. O aprimoramento da eficiência
operacional e a consecução dos escopos propostos constituem os principais
focos desta investigação. \cite{de2011associaccao}
